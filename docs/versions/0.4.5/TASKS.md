### 可执行的状态验收序列

所有序列使用合成身份和安全任务文本；真实测试只记录观察结果，不存原始报文。

| 序列 | 通过判据 |
| --- | --- |
| 开始 → 请求 → 工具开始/成功 → Stop | 登记 idle 但不占屏 → starting → working/thinking → completed；一轮独立计时 |
| 请求 → PermissionRequest → 批准后工具成功 | 等待期间 waiting_approval，后续工具结果清除等待；设备不代批 |
| 请求 → PermissionRequest → 拒绝 | 记录实际后续事件；工具失败不直接变整轮 failed，无后续事件不伪造完成 |
| 请求 → AskUserQuestion → 结果 | waiting_user 后恢复 thinking；未覆盖的其他输入通道明确列限制 |
| 工具失败 → 后续工具 → Stop | 失败摘要后允许继续，最后正常 completed |
| StopFailure / Stop 后继续 / SessionEnd | 分别验证 failed、同轮恢复、冻结与 60 秒清理，不混为取消 |
| 第二次请求 / resume / Host 重启 | 新请求计时归零且更新主项；resume 保留；重启冻结待确认再恢复 |
| 两来源各两会话交错更新 | 标题/状态/耗时互不串写，仅新有效请求切主项，其他事件不抢焦点 |

H1/H2 覆盖合成序列，V 覆盖实际来源；缺失因果信息的跨轮迟到事件只验证已定义限制。
兼容矩阵至少包含 0.4.5 Host→0.3 固件、0.4.5 Host→0.4 固件、
0.4 Host→0.4.5 固件、0.4.5 Host→0.4.5 固件；必须明确单任务降级或 multi-session 模式。
