# Saki 0.4.0 开发说明

状态：已归档的开发预览，未单独发布；相关能力已并入 0.4.5。历史实施证据见
[实施任务](../versions/0.4.0/TASKS.md)，完整真机矩阵统一在 1.0 候选执行。

- 支持 Codex 与 Claude Code 多个独立 Session，共用一个 Host；不包含 subagent 树。
- Host 合计 32 项、屏幕最多 4 项，独立状态/计时、最新提交主屏与注意优先级侧栏、过期与恢复。
- 主屏支持从新请求中本地提取短目标（48 字符/96 UTF-8 B）。标题可能保留用户原文片段，
  并进入 IPC、私有检查点及设备；规则过滤不保证覆盖所有敏感内容，见
  [隐私契约](../versions/0.4.0/SPEC.md#2-身份来源和隐私)。
- 新增 Claude Code hook 安装/校验/卸载、HMAC 身份与私有脱敏检查点、显示清理命令。
- 固件增加主屏/侧栏与详情和 capability 协商的 v1 完整集合；旧 Host/固件保留单任务兼容。
- Claude Code 2.1.270 单 Session 真实 API 生命周期 probe 已通过。本开发预览未创建独立
  candidate、tag 或 Release。

安装、配置范围选择和来源信号限制见 [0.4 用户指南](../versions/0.4.0/USER_GUIDE.md)。
