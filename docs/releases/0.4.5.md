# Saki 0.4.5 发布说明

## 更新内容

- 支持 Codex / Claude Code 多 Session，Host 最多跟踪 32 项，设备最多显示 4 项。
- 提供 Claude Code 用户级或项目级 hook 安装、检查和卸载，复用本地 Host。
- 主屏保持最新提交任务，侧栏展示其他任务；仅打开客户端的空闲会话不再占屏。
- 已完成任务保留 60 秒，未开始的空闲会话不会挤走完成反馈。
- 支持规则过滤后的短任务目标，明确标题会经过本地 IPC、私有检查点及设备；规则不是完整匿名化。

## 验证与范围

0.4.5 按用户本地 Claude Code 确认和此前 173 项自动化测试、Ruff、whitespace 结果发布；
版本元数据调整后没有追加新的通过声明。详细时间线见
[冻结的发布记录](../versions/0.4.5/TASKS.md)。0.x 的完整真机矩阵不作为本版本发布后继续
悬挂的验收，统一进入 [1.0 发布前门槛](../ROADMAP.md#10-发布前真机门槛)。

未开始会话隐藏后，设备空屏仍显示 Agent / 空闲 / 暂无会话；这是待机页面，
不代表残留的 Claude 会话。该视觉调整暂缓。

## 安装与构建

Host 安装与 hook 配置见 [用户指南](../versions/0.4.5/USER_GUIDE.md)。
Host 版本为 0.4.5，固件 dev 为 0.4.5-dev、release 为 0.4.5。
使用 `scripts/package-release.zsh --final` 从干净提交生成固件包与校验文件；
打 tag 不等于已经生成或验证固件包。包不包含原厂备份或本机配置。
