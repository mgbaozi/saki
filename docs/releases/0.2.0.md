# Saki 0.2.0 发布说明

> 当前状态：内部 release candidate，尚未达到最终发布条件。

## 首版能力

- 通过 USB CDC 自动发现 ESP32S3 BOX3，不依赖固定串口路径；
- 显示 Codex 的启动、思考、工作、等待用户、等待批准、完成、失败、取消和空闲状态；
- 支持中英文标题与动作摘要、设备端执行时间和确定/未知/无进度三种模式；
- 支持触摸切换摘要/详情、15 秒详情自动返回，以及暗屏首次点击仅唤醒；
- 支持活动、空闲、断线三档视觉亮度，并在新状态到达时恢复正常亮度；
- Codex hooks 经 Mac Host 脱敏、合并后发送，不传输隐藏思维链或完整工具输出；
- hook 文本中的 HTML 空白实体会恢复为普通空格，不再把 `&#x20;` 显示到任务标题；
- 支持 ACK/重试、心跳、断线覆盖层、快速热插拔恢复和 120 秒 Agent 事件停滞兜底；
- `doctor` 可检查协议诊断、heap 和 app/UI/USB stack 安全余量；
- 提供 macOS LaunchAgent 的安装、状态、日志、重启和卸载命令。

## 已完成验证

- 78 项 Host/协议/文档与仓库可移植性测试和 Ruff 检查通过；
- 17 项 ESP-IDF Unity 真机测试：`0 Failures`，包括详情、唤醒、亮度 deadline 和透明度映射；
- 40 个确定性非法输入 case 后，同一 CDC 连接可重新握手、应用状态并心跳；
- dev 真机运行时最低余量：内部 heap 182,079 bytes，app/UI/USB stack 分别为
  2,116/4,896/5,552 bytes；
- 小样本 USB 物理拔插 3/3 恢复，恢复时间 448.4–1,092.4 ms；
- 最新 release app 镜像 923,648 bytes，2 MiB app 分区剩余 1,107,968 bytes（55%）。
- release 真机 soak smoke 完成 100/100 状态：ACK P95 105.5 ms，全部协议异常增量为 0，
  内部 heap 历史低点 198,963 bytes；24 小时报告作为扩展验证暂缓。
- release 真机 12 个 hook 源时间戳到设备 ACK 样本平均 114.6 ms、P95/最大 169.4 ms；
  该指标精确覆盖到 UI 入队；LCD 最后像素的光学测量不作为当前版本发布门槛。

## 发布前剩余项

以下项目完成前不得把候选包改名为最终 `0.2.0`：

- 完成 `SPEC.md` 12.1 的最终功能验收；
- Host 版本仍为 `0.2.0.dev0`，最终发布时须改为 `0.2.0`；
- 最终发布提交和 `v0.2.0` tag 尚未创建。

项目所有者于 2026-09-04 决定暂缓 24 小时/10,000 次 soak、Mac
睡眠/唤醒和 Agent hook→LCD 最后像素光学延迟测量。这三项保留测试工具和方法，但不再是
`0.2.0` blocker；USB 物理拔插 3/3、100 次 soak smoke 和 hook→设备 ACK 延迟已经通过。

release profile 已在目标设备上通过 `doctor`、状态回放、40-case fuzz 和恢复
验证。加入 UI policy 的最新候选重新刷入后，`doctor` 报告协议异常计数全为 0，内部 heap
历史低点为 199,951 bytes，app/UI/USB stack 最低值为 2,668/6,192/6,984 bytes；
LaunchAgent 随后重新占用正确的 Saki 应用端口。

## 已知范围

- 0.2.0 只支持 USB；BLE 与 Wi-Fi fallback 计划在后续阶段实现；
- USB 以物理访问为信任边界，不提供应用层加密；
- 三档亮度由 LVGL 遮罩实现；目标板背光脚只提供使能，因此该功能不会降低背光功耗；
- 内置字体覆盖 GB2312 常用简体中文，范围外字符可能显示替代字形；
- Agent 平台未发出终止 hook 时，Host 只能在 120 秒后显示通用的“请检查 Mac”，不会猜测
  具体错误原因。

候选包、版本、校验值和构建环境以包内 `BUILD-INFO.txt` 与 `SHA256SUMS` 为准。
