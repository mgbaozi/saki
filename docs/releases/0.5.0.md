# Saki 0.5.0 发布说明

## 更新内容

- 将 Codex / Claude Code 对接收敛为显式 `AdapterSpec` 注册表；公共 Host 从 `SourceEvent`
  开始只处理与产品无关的语义事件，新增来源不再要求修改 SessionRegistry 或设备状态机。
- 增加 `generic-source` 能力协商。0.5 Host/固件可显示有界通用 Agent 标签；连接旧固件时
  保留 Codex / Claude Code wire key，未来来源安全降级为 `legacy / Agent`。
- 新增设备端素材包架构。默认 `Saki Stage` 提供九种状态图片和可关闭轻量文案，`经典`
  保留无图片回退；协议和 Host 不传输角色素材。
- 最近会话侧栏改用状态和任务标题，不再显示四位 HMAC；底栏仅在确有隐藏注意项时显示
  `待处理 N`。运行态过期 15 分钟后退出投影，失败记录保留 10 分钟。
- 修复 Claude Code 标题回退、紧凑布局计时错位、全角破折号字形、LCD 异步刷新残影，以及
  非均匀九宫格素材被几何等分造成的相邻图标串入。

## 视觉设置

- 短按 K1：切换轻量文案开关。
- 按住 K1 2–5 秒后松开：切换 `Saki Stage` / `经典` 素材包。
- K2 的 BLE 重连、配对和清除绑定手势保持不变。

默认主题包含 AI 辅助生成的非官方同人角色形象。它不包含官方图片、Logo 或提取资源，相关
角色与作品权利归各自权利人，且该主题不适用 Apache-2.0。完整声明见 release 包中的 `NOTICE`；
不希望使用该素材时可切换到 `经典`。
